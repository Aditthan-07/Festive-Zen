# 🪔 Festive-Zen

An interactive, ambient bilingual greeting experience featuring festive celebration visuals, dynamic Tamil and English wishes, and personalized greeting links.

## ✨ Features
- **Cinematic Celebration:** Smooth HD celebration backdrop with custom framing.
- **Bilingual Wishes:** Timed alternating greetings in English and Tamil (Anek Tamil & Arima Madurai typography).
- **Interactive Deepam:** Interactive earthen Diya canvas with stoke and particle effects.
- **Personalized Sharing:** One-click custom name link generation for WhatsApp and direct sharing.

## 🚀 Quick Run
```bash
python -m http.server 3000
```
