# 🪔 Festive-Zen | Interactive Diwali Celebration & Greeting Web Experience

An interactive, glassmorphic Diwali greetings web application with cinematic celebration visuals, bilingual wishes, personalized link generation, and festive animations.

## ✨ Features

- **Cinematic Video Background:** Seamless 60fps festive video loop with radial vignette scrim for optimal contrast and readable typography.
- **Glassmorphic Greeting Card:** Balanced centered container with warm ambient gold borders and two-tier greeting heading (`HAPPY DIWALI FROM [NAME]`).
- **Interactive Handcrafted Diya:** Vector earthenware Deepam with 4-layered animated flickering flame, ambient radial glow, and interactive stoke sparkles on tap.
- **Hanging Toran & Fairy Lights:** Decorative marigold garland and jewel-toned incandescent fairy lights (Gold, Ruby, Emerald, Amber, Sapphire) with gentle physics and twinkle animations.
- **HTML5 Canvas Fireworks:** Non-blocking 60fps particle physics fireworks engine with interactive launch on background clicks.
- **Bilingual Sequential Greetings:** Smoothly alternates between short English and Tamil greetings with a 5.5s timer, hover-pause interaction, zero layout shifts (CSS Grid area stack), and a manual `English | தமிழ்` switcher.
- **Authentic Typography:** Features Google Fonts `Cinzel`, `Great Vibes`, `Poppins`, `Anek Tamil` (modern lead text), and `Arima Madurai` (calligraphic Tamil wishes).
- **Name Personalization & Sharing Engine:**
  - **Set My Name:** Real-time heading update with animated gold shimmer.
  - **Generate Share Link:** Automatically copies personalized `?name=...` URL to clipboard with toast notification.
  - **WhatsApp Direct Share:** Pre-formats personalized Diwali wishes with direct sharing link.
  - **Inbound Query Param:** Dynamically personalizes card upon page load from shared URL.
- **Zero Dependencies:** Pure vanilla HTML5, CSS3, and modern JavaScript. Self-contained local assets.

## 🚀 Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/Aditthan-07/Festive-Zen.git
   cd Festive-Zen
   ```
2. Start any local HTTP server:
   ```bash
   # Python 3
   python -m http.server 3000
   ```
3. Open in your browser:
   [http://localhost:3000](http://localhost:3000)
